# plugin_node 命令実装状況とTODO

公式TypeScript版（`nadesiko3/src/plugin_node.mts`）で定義されている命令（全105件）のgonako（Go版 `internal/nodelib`）における実装状況とTODOリストです。

---

## 1. 基本方針 (AGENTS.md §3 より)

- `stdlib`（`plugin_system` 相当）と異なり、`nodelib` は**TypeScript版との厳密な互換保証の対象外**です。
- 命令名・助詞は既存スクリプトの可読性のためTypeScript版に合わせますが、動作や設計はGo言語らしく最適化・再設計して実装します。
- 現状: **70 / 105 件 実装済み (約66.7%)**
