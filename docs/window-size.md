# 母艦ウィンドウの設定

gonako-guiのメインウィンドウ（母艦）のサイズ、位置、状態などを、なでしこ命令または
プロジェクトフォルダの`index.json`で指定する方法を定めます。

この仕様はIssue #84（実行中のウィンドウ操作）、Issue #85（起動時の設定）、
Issue #112（ライトモードとダークモード）に対応します。
アスペクト比の固定はOSごとに意味と挙動が異なるため、この仕様には含めません。

## ウィンドウハンドル

システム定数`母艦`の値は`0`です。これは実行中のgonako-guiのネイティブウィンドウを
表す論理ハンドルです。OSのポインタやウィンドウIDはなでしこプログラムへ公開しません。

現時点で`ウィンドウ変更`と`ウィンドウ取得`が受け付けるのは`母艦`だけです。
将来、同一プロセス内で複数ウィンドウを管理する場合も、正の論理ハンドルを追加して
同じ命令を利用できる設計とします。

## ウィンドウ変更

設定辞書で指定した項目だけを変更します。

```nako3
設定＝{
  "サイズ": [640, 480],
  "位置": "中央",
  "状態": "通常"
}
設定で母艦のウィンドウ変更。
```

設定項目は次の通りです。

| 項目 | 値 | 説明 |
|---|---|---|
| `サイズ` | `[幅, 高さ]` | ウィンドウの幅と高さ。正の整数で指定する |
| `位置` | `"中央"`または`[X, Y]` | 中央配置、または画面の左上を原点とする座標 |
| `状態` | `"通常"`、`"最大化"`、`"最小化"`、`"全画面"` | ウィンドウの表示状態 |
| `タイトル` | 文字列 | タイトルバーに表示する文字列 |
| `サイズ変更可` | 真偽値 | ユーザーによるサイズ変更を許可するか |
| `テーマ` | `"ライト"`、`"ダーク"`、`"自動"` | ウィンドウの配色。省略時は`"自動"`（OSの設定に従う） |

位置の座標には、左側や上側に配置したディスプレイを表す負の整数も指定できます。
存在しないハンドル、不正な設定値、GUIウィンドウを持たない実行環境ではエラーにします。

## ウィンドウ取得

現在のウィンドウ情報を辞書で返します。

```nako3
情報＝母艦のウィンドウ取得。
情報をJSON整形して表示。
```

戻り値には`サイズ`、`位置`、`状態`、`タイトル`、`サイズ変更可`、`テーマ`が含まれます。
`テーマ`は指定中の値（`"ライト"`、`"ダーク"`、`"自動"`）です。

## index.json

HTMLプロジェクト、または単一実行ファイルへ変換するプロジェクトフォルダの
`index.json`に、`ウィンドウ変更`と同じ設定辞書を記述できます。

```json
{
  "サイズ": [640, 480],
  "位置": "中央",
  "状態": "通常",
  "タイトル": "見本アプリ",
  "サイズ変更可": true,
  "テーマ": "ダーク"
}
```

gonako-guiへHTMLフォルダまたはHTMLファイルを渡した場合は、表示前に同じフォルダの
`index.json`を読み込みます。フォルダを単一実行ファイルへ変換した場合、`index.json`は
ほかのリソースと一緒に梱包され、起動時に表示前の設定として適用されます。

HTMLフォルダをgonako-guiで直接開く場合の優先順位は次の通りです。

1. 明示した`-title`、`-width`、`-height`、`-theme`コマンドラインオプション
2. `index.json`
3. gonako-guiの既定値

単一実行ファイルの場合は、`index.json`、変換時に指定したタイトル、gonako-guiの
既定値の順です。変換後の実行ファイルは起動オプションをウィンドウ設定として扱いません。

内蔵エディタで`.nako3`ファイルを開いただけでは、そのファイルと同じフォルダの
`index.json`をエディタ自身には適用しません。変換した実行ファイルの起動時に適用します。

`index.json`がない場合は従来の既定値を使います。ファイルが存在するのにJSONや設定値が
不正な場合は、設定を黙って無視せず起動エラーとして通知します。

## テーマ（ライトモード・ダークモード）

`テーマ`には次の値を指定できます。英語名（`light`、`dark`、`auto`）も使えます。

| 値 | 意味 |
|---|---|
| `"ライト"` | 明るい配色に固定する |
| `"ダーク"` | 暗い配色に固定する |
| `"自動"` | OSの外観設定に従う（既定値） |

テーマを指定すると、gonako-guiは次の処理を行います。

- タイトルバーなど、ウィンドウのネイティブ部分の配色を切り替える
- 表示するページの`<html>`要素へ`data-gonako-theme`属性を付ける。値は実際に使う配色で、
  `"自動"`のときもOSの設定から判断した`light`または`dark`になる
- `"ライト"`または`"ダーク"`のときは、`<html>`要素のCSSプロパティ`color-scheme`を
  `light`または`dark`に固定する。独自の配色を持たないページでも、背景色や文字色、
  入力欄などのブラウザ標準の配色がテーマに合う
- テーマが変わると、`window`で`gonako-theme-change`イベントを発生させる
  （`event.detail.theme`は指定値、`event.detail.resolved`は実際の配色）

`"自動"`のときは`color-scheme`を変更しないため、従来のページの見た目は変わりません。

### HTMLでテーマに合わせる

どのOSでも確実に判定できるよう、`data-gonako-theme`属性でスタイルを切り替える方法を
おすすめします。

```css
body { background: #fff; color: #222; }

:root[data-gonako-theme="dark"] body {
  background: #1e1e2e;
  color: #cdd6f4;
}
```

macOSでは、ウィンドウの配色に合わせてCSSの`prefers-color-scheme`も切り替わります。
WindowsのWebView2では`prefers-color-scheme`が常にOSの設定に従います。Linuxでは
WebKitGTKのバージョンによって追従するかどうかが異なります。テーマを固定する場合は
`data-gonako-theme`属性を使ってください。

gonako-guiが用意する画面（変換した実行ファイルの実行画面、ブラウザ(wnako3)実行画面、
エラー表示画面）も、この属性で配色を切り替えます。

### OSごとの実装

| OS | ウィンドウの配色 | 備考 |
|---|---|---|
| macOS | `NSWindow.appearance`をAqua / DarkAquaに設定する。自動なら`nil`に戻す | WKWebViewの`prefers-color-scheme`も追従する |
| Windows | `DwmSetWindowAttribute`の`DWMWA_USE_IMMERSIVE_DARK_MODE`でタイトルバーを切り替える | 自動のときは起動時・変更時のレジストリ`AppsUseLightTheme`で判断する |
| Linux | GTKの`gtk-application-prefer-dark-theme`を切り替える | GTKの設定はアプリ全体に効く。自動に戻すと起動時の値へ戻す |

## 実装上の境界

`internal/guilib`は論理ハンドルと設定値だけを扱い、ネイティブウィンドウ操作は
gonako-gui側の`WindowController`実装へ委譲します。WebViewの操作はUIスレッドで実行し、
位置、状態、サイズ変更可、テーマの処理はmacOS、Windows、Linuxごとに実装します。
OSから指定中のテーマを読み戻せない環境があるため、指定したテーマはgonako-gui側で
ウィンドウごとに記録し、`ウィンドウ取得`ではその値を返します。
