# 母艦ウィンドウの設定

gonako-guiのメインウィンドウ（母艦）のサイズ、位置、状態などを、なでしこ命令または
プロジェクトフォルダの`index.json`で指定する方法を定めます。

この仕様はIssue #84（実行中のウィンドウ操作）とIssue #85（起動時の設定）に対応します。
アスペクト比の固定はOSごとに意味と挙動が異なるため、この仕様には含めません。

## ウィンドウハンドル

システム定数`母艦`の値は`0`です。これは実行中のgonako-guiのネイティブウィンドウを
表す論理ハンドルです。OSのポインタやウィンドウIDはなでしこプログラムへ公開しません。

現時点で`ウィンドウ変更`と`ウィンドウ取得`が受け付けるのは`母艦`だけです。
将来、同一プロセス内で複数ウィンドウを管理する場合も、正の論理ハンドルを追加して
同じ命令を利用できる設計とします。

## ウィンドウ変更

設定辞書で指定した項目だけを変更します。

```nako3
設定＝{
  "サイズ": [640, 480],
  "位置": "中央",
  "状態": "通常"
}
設定で母艦のウィンドウ変更。
```

設定項目は次の通りです。

| 項目 | 値 | 説明 |
|---|---|---|
| `サイズ` | `[幅, 高さ]` | ウィンドウの幅と高さ。正の整数で指定する |
| `位置` | `"中央"`または`[X, Y]` | 中央配置、または画面の左上を原点とする座標 |
| `状態` | `"通常"`、`"最大化"`、`"最小化"`、`"全画面"` | ウィンドウの表示状態 |
| `タイトル` | 文字列 | タイトルバーに表示する文字列 |
| `サイズ変更可` | 真偽値 | ユーザーによるサイズ変更を許可するか |

位置の座標には、左側や上側に配置したディスプレイを表す負の整数も指定できます。
存在しないハンドル、不正な設定値、GUIウィンドウを持たない実行環境ではエラーにします。

## ウィンドウ取得

現在のウィンドウ情報を辞書で返します。

```nako3
情報＝母艦のウィンドウ取得。
情報をJSON整形して表示。
```

戻り値には`サイズ`、`位置`、`状態`、`タイトル`、`サイズ変更可`が含まれます。

## index.json

HTMLプロジェクト、または単一実行ファイルへ変換するプロジェクトフォルダの
`index.json`に、`ウィンドウ変更`と同じ設定辞書を記述できます。

```json
{
  "サイズ": [640, 480],
  "位置": "中央",
  "状態": "通常",
  "タイトル": "見本アプリ",
  "サイズ変更可": true
}
```

gonako-guiへHTMLフォルダまたはHTMLファイルを渡した場合は、表示前に同じフォルダの
`index.json`を読み込みます。フォルダを単一実行ファイルへ変換した場合、`index.json`は
ほかのリソースと一緒に梱包され、起動時に表示前の設定として適用されます。

HTMLフォルダをgonako-guiで直接開く場合の優先順位は次の通りです。

1. 明示した`-title`、`-width`、`-height`コマンドラインオプション
2. `index.json`
3. gonako-guiの既定値

単一実行ファイルの場合は、`index.json`、変換時に指定したタイトル、gonako-guiの
既定値の順です。変換後の実行ファイルは起動オプションをウィンドウ設定として扱いません。

内蔵エディタで`.nako3`ファイルを開いただけでは、そのファイルと同じフォルダの
`index.json`をエディタ自身には適用しません。変換した実行ファイルの起動時に適用します。

`index.json`がない場合は従来の既定値を使います。ファイルが存在するのにJSONや設定値が
不正な場合は、設定を黙って無視せず起動エラーとして通知します。

## 実装上の境界

`internal/guilib`は論理ハンドルと設定値だけを扱い、ネイティブウィンドウ操作は
gonako-gui側の`WindowController`実装へ委譲します。WebViewの操作はUIスレッドで実行し、
位置、状態、サイズ変更可の処理はmacOS、Windows、Linuxごとに実装します。
