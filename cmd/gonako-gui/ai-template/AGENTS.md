# なでしこ3 AI開発ガイド

## このプロジェクトについて

- 「なでしこ3」は、日本語でプログラムを書ける日本語プログラミング言語「なでしこ」の現行版です。
- 公式サイト: [なでしこ公式サイト](https://nadesi.com/)
- このプロジェクトでは、なでしこ3のGo言語版である `gonako` で動くプログラムを作成します。ブラウザ版やNode.js版だけの命令があるため、利用できる命令は必ず `gonako doc` で確認してください。
- 詳しい文法: [なでしこ3 文法](https://github.com/kujirahand/nadesiko3/blob/master/doc/syntax-nako3.md)

## 応答と言語

- AIは必ず日本語で応答してください。
- プログラムはUTF-8のなでしこ3ファイル（拡張子: `.nako3`）として作成してください。
- なでしこ3は日本語で記述しますが、自由な自然言語ではありません。以下の文法、実在する命令名、命令ごとに決められた助詞を守ってください。

## 命令とマニュアルの調べ方

コードを書く前に、利用する命令の名前、書式、助詞を検索してください。意味から命令名や助詞を推測してはいけません。

```sh
gonako doc キーワード            # 組み込みの命令一覧を検索
gonako doc キーワード --json     # AIが読みやすいJSON形式
gonako doc キーワード --web      # Webのマニュアルも検索
```

複数の語はAND検索になります。検索結果に命令がなければ、別のキーワードで検索するか、実現方法を見直してください。

## 基本文法

### 文、コメント、値

- 文は改行または `。` で区切ります。
- 行コメントは `#`、範囲コメントは `/*` と `*/` を使います。
- 数値は `123`、真偽値は `真` と `偽` です。
- `「...」` と `"..."` は `{変数名}` を展開します。`『...』` と `'...'` は展開しません。
- 四則演算は `+ - * / %`、比較は `= == != > < >= <=`、論理演算は `かつ` と `または` を使えます。複雑な式は丸括弧で囲んでください。

```nako3
名前は「なでしこ」
年齢=3
「{名前}{年齢}です」と表示
```

### 変数、配列、辞書

- 代入は `答は0` または `答=0` と書きます。
- 配列は `[10,20,30]`、辞書は `{"名前":"なでしこ","年齢":3}` と書きます。
- 配列の添字は0から始まります。要素の参照と代入には `一覧[0]`、辞書には `人物["名前"]` を使います。`一覧@0` の形式でも参照できます。
- 変数名に助詞を含めないでください。命令名と同じ変数名も避けてください。

```nako3
一覧=[10,20,30]
人物={"名前":"なでしこ","年齢":3}
一覧[0]=99
「{人物["名前"]}: {一覧[0]}」と表示
```

### 命令、助詞、連文

- 命令は原則として `引数＋助詞＋命令名` の順です。例えば `「こんにちは」と表示` と書きます。
- 助詞は単なる飾りではなく、引数の割り当てに使われます。`gonako doc` の検索結果に記載された助詞だけを使ってください。
- 命令の結果は特殊変数 `それ` に入ります。
- `AしてB` という連文では、Aの戻り値がBの最初の引数に渡ります。例えば `3に5を足して表示` は、加算結果を表示します。

### 条件分岐とブロック

- 複数行のブロックは、行末に `:` を付け、次の行を半角空白でインデントする書式を推奨します。`:` の直後には必ず改行してください。
- `:` を使わない場合は、ブロックの最後に `ここまで` が必要です。
- 等しいかの判定には `=` または `==` を使います。代入と混同しないよう、条件式を丸括弧で囲むと安全です。

```nako3
もし、(年齢>=18)ならば:
  「成人です」と表示
違えば:
  「未成年です」と表示
```

### 繰り返し

- `N回:` では、現在の回数を `回数` で参照できます。
- `Iで1から10まで繰り返す:` の範囲には、開始値と終了値の両方を含みます。
- `要素で一覧を反復:` で各要素を処理できます。変数名を省略した場合、現在の要素は `対象` に入ります。
- `条件の間:` で、条件が真の間だけ繰り返します。

```nako3
答=0
Iで1から10まで繰り返す:
  答=答+I
「合計は{答}です」と表示
```

### ユーザー定義関数

- 引数は `変数名＋助詞` で定義します。呼び出すときも同じ助詞を使ってください。
- `関数` の別名として `●` を使えます。
- 値は `値を戻す` または `値で戻る` で返します。
- 標準命令と見分けやすくするため、ユーザー定義関数名の末尾には「処理」を付けることを推奨します。

```nako3
●(AとBの)加算処理とは:
  A+Bを戻す

答=3と5の加算処理
答を表示
```

## アプリの種類と実行・検証方法

作るアプリの種類によって、実行方法と使える命令が違います。最初に種類を決めてください。

### コンソール(CLI)アプリ

画面部品を使わず、文字の入出力だけで動くアプリです。

```sh
gonako run main.nako3     # 実行する
gonako lint main.nako3    # 実行せずに文法だけ確認する
```

### GUI(ウィンドウ)アプリ

`ボタン作成` や `キャンバス作成` などのGUI命令を使うアプリです。

- GUI命令はCLI版の `gonako` には登録されていません。`gonako doc` ではGUI命令も検索できますが、`gonako run` や `gonako lint` ではGUI命令を含むプログラムはエラーになります。GUIアプリの確認に `gonako run` を使わないでください。
- GUIアプリは次のコマンドで直接実行します。エディタは開かず、専用ウィンドウでプログラムが動きます。

```sh
gonako-gui run main.nako3
```

- エディタで開いて実行する場合は `gonako-gui main.nako3` で開き、ツールバーの「種類」を「ウィンドウ(GUI)」にして実行ボタンを押します。「ウィンドウ(GUI)」では母艦が実行用の実ウィンドウを指します。エディタ内のインライン実行では母艦は疑似ウィンドウになり、実際のウィンドウは動きません。

### ブラウザ(wnako3)アプリ

タートルなどブラウザ版なでしこ専用の命令を使う場合は、`gonako-gui` で開き、「種類」を「ブラウザ(wnako3)」にして実行します。タートルは「ウィンドウ(GUI)」では使えません。

### 検証方法

- CLIアプリは、作成後に必ず実行し、標準出力が期待どおりかを確認してください。
- GUIアプリは、計算などのロジックを関数に分けて作ってください。画面表示が要らない部分は、小さなCLIプログラムとして切り出せば `gonako run` で確認できます。
- キャンバスの描画結果は、`キャンバス画像保存` でPNGファイルに書き出して確認できます。
- GUIアプリはウィンドウが開いたまま終了しません。AIエージェントが起動確認をする場合は、起動したプロセスを自分で止めてください。最終的な画面操作や見た目の確認は、利用者に依頼してください。
- エラーになった場合は、エラーメッセージと行番号を読んでから `gonako doc` で命令名・書式・助詞を再確認し、修正と実行を繰り返してください。
- `gonako-gui run` は、ウィンドウを開く前に文法と命令の確認を行います。間違いがあれば標準エラーにメッセージが出て、終了コード1で終わります。Windowsのリリース版で標準エラーの宛先が無いときは、同じ文面をメッセージボックスで表示します。実行中のエラーはウィンドウの中に表示されます。

### 配布方法

- GUIアプリを配布するには、エディタのメニュー「実行ファイルに変換」を使います。プログラムが単一の実行ファイルになり、受け取る側にランタイムは要りません。
- `gonako build` の既定の土台はCLI版なので、GUIアプリの配布にはそのまま使わないでください。

## GUIアプリの作り方

GUI命令の書式は、必ず `gonako doc` で確認してください。エディタ左側の「ひな形」タブにもGUIのサンプルがあります（フォーム、キャンバス描画など）。

- 画面部品を作る命令には、`ラベル作成`、`エディタ作成`、`テキストエリア作成`、`ボタン作成`、`フォーム作成`、`チェックボックス作成`、`セレクトボックス作成`、`キャンバス作成`、`画像作成` などがあります。作成した部品は数値のハンドル（部品番号）で返ります。
- 部品の文字は `テキスト設定` で変え、`テキスト取得` で読みます。
- イベントは `ボタンをクリックした時には` のように書きます。ほかに `変更時`、`フォーム送信時`、`ファイルドロップ時` があります。
- `表示` は文字列を安全なテキストとして画面に追加します。HTMLタグを配置したい場合だけ `HTML表示` を使ってください。入力された値をそのまま `HTML表示` に渡さないでください。
- `DOM親要素設定` で、部品を追加する親要素を切り替えられます。
- ダイアログには `言う`、`尋ねる`、`二択`、`ボタン選択`、`リスト選択` があります。ファイルやフォルダをOS標準ダイアログで選ぶには `ファイル選択`、`保存ファイル選択`、`フォルダ選択` を使います。
- ウィンドウ（母艦）の大きさやタイトルは `母艦のウィンドウ変更` で変えられ、現在値は `母艦のウィンドウ取得` で取得できます。

```nako3
{"サイズ":[640,480],"位置":"中央"}で母艦のウィンドウ変更
母艦のウィンドウ取得
```

フォームの例です。

```nako3
「<h2>簡単なフォーム</h2>」をHTML表示
「名前:」のラベル作成
名前入力=「太郎」のエディタ作成
挨拶ボタン=「挨拶する」のボタン作成
結果ラベル=「」のラベル作成

挨拶ボタンをクリックした時には
　名前=名前入力のテキスト取得
　結果ラベルに「こんにちは、{名前}さん！」をテキスト設定
ここまで
```

## ゲームの作り方

ゲームは「状態を変数に持つ → タイマーで状態を更新する → キャンバスを消去して描き直す」の繰り返しで作ります。操作にはボタンやキャンバスへのクリックイベントを使います。

### キャンバス描画

- `絵=[320,200]のキャンバス作成` のように、大きさ `[幅,高さ]` を指定して描画領域を作ります。戻り値のハンドルを描画先に指定します。
- 座標は左上が `[0,0]` で、Xは右向き、Yは下向きです。

| 命令 | 書き方 | 内容 |
| --- | --- | --- |
| キャンバス線描画 | `絵の[X1,Y1,X2,Y2]へキャンバス線描画` | 直線 |
| キャンバス矩形描画 | `絵の[X,Y,幅,高さ]へキャンバス矩形描画` | 塗りつぶした矩形 |
| キャンバス円描画 | `絵の[中心X,中心Y,半径]にキャンバス円描画` | 塗りつぶした円 |
| キャンバス画像描画 | `絵に「画像.png」を[X,Y]でキャンバス画像描画` | 画像ファイルの描画 |
| キャンバス消去 | `絵をキャンバス消去` | 全体を消す |

- 線や塗りの色と線の太さは、描画の前に `キャンバス線色設定`、`キャンバス塗色設定`、`キャンバス線太設定` で決めます。描画命令自体に色の引数はありません。色はCSSの色名（`red` など）か `#RRGGBB` で指定します。

```nako3
絵に「navy」をキャンバス線色設定
絵に「orange」をキャンバス塗色設定
絵の[240,80,45]にキャンバス円描画
```

### タイマーとアニメーション

- `関数を0.05秒毎` で、関数を一定間隔で繰り返し呼べます。コールバックの中では `対象のタイマー停止` で自分のタイマーを止められます。1回だけ遅らせたいときは `秒後`、処理を待つときは `N秒待つ` を使います。
- `画像新規作成` や `画像線描画` などの画像命令は、メモリ上の画像を作るためのもので、キャンバスとは別物です。画面にアニメーションを表示するにはキャンバスを使ってください。

落ちてくる円を描き続ける例です。

```nako3
絵=[320,240]のキャンバス作成
Y=0
描画=関数()
  絵をキャンバス消去
  絵に「#4488ff」をキャンバス塗色設定
  絵の[160,Y,20]にキャンバス円描画
  Y=Y+2
  もし、(Y>260)ならば
    Y=0
  ここまで
ここまで
描画を0.05秒毎
```

## 作成後の確認

作成・修正したプログラムは必ず実行し、期待する結果になることを確認してください。実行コマンドはアプリの種類で違います。

```sh
gonako run main.nako3       # コンソール(CLI)アプリ
gonako-gui run main.nako3   # GUI(ウィンドウ)アプリ
```

エラーになった場合は、エラーメッセージを読んでから `gonako doc` で命令名・書式・助詞を再確認し、修正と実行を繰り返してください。
