# なでしこ3 AI開発ガイド

## 応答と言語

- AIは必ず日本語で応答してください。
- プログラムはUTF-8の「なでしこ3」ファイル（拡張子: `.nako3`）として作成してください。
- 命令名や助詞を推測で作らず、実在する命令を確認してから使ってください。

## 命令とマニュアルの調べ方

gonakoには、AIからも利用しやすい命令・マニュアル検索があります。

```sh
gonako doc キーワード            # 組み込みの命令一覧を検索
gonako doc キーワード --json     # AIが読みやすいJSON形式
gonako doc キーワード --web      # Webのマニュアルも検索
```

検索結果の書式と助詞を守ってください。複数の語はAND検索になります。

## 文法メモ

- 文は改行または「。」で区切ります。コメントは `#` または `//` から行末までです。
- 文字列は `「こんにちは」` または `『こんにちは』` と書きます。`「答えは{答}です」` のように値を展開できます。
- 代入は `答=0`、配列は `一覧=[1,2,3]`、辞書は `人物={"名前":"なでしこ"}` のように書きます。配列の添字は0から始まります。
- 命令は原則として「値＋助詞＋命令名」の順です。例: `「こんにちは」と表示`。命令ごとに利用可能な助詞が決まっています。
- 条件分岐や繰り返しのブロックは、末尾に `:` を付け、半角空白でインデントします。

```nako3
合計=0
Iで1から10まで繰り返す:
  合計=合計+I

もし、合計=55ならば:
  「合計は{合計}です」と表示
違えば:
  「計算に失敗しました」と表示
```

- 関数は引数名と助詞を組にして定義します。ユーザー定義関数名の末尾には「処理」を付けることを推奨します。

```nako3
●(AとBの)加算処理とは:
  A+Bを戻す

3と5の加算処理して表示
```

## 作成後の確認

作成・修正したプログラムは必ず実行し、結果またはエラーを確認してください。

```sh
gonako run main.nako3
```

エラーになった場合は、まず `gonako doc` で命令名・書式・助詞を再確認してから修正し、再実行してください。
